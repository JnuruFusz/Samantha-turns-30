# Nacho Average 30th Fiesta

A birthday invitation site for Samantha Elaine Goodwin.

Born October 14. Celebrating October 18.

## Local

```bash
npm install
npm run dev
```

## Host on Netlify

1. Push this folder to GitHub.
2. In Netlify, add a new site from that GitHub repo.
3. Build command: `npm run build`
4. Publish directory: `dist`
5. After the first deploy, Netlify Forms will collect RSVPs.

RSVPs show up in Netlify → Forms.

## Adding photos

The Highlight Reel tells Sammi's story one chapter at a time, oldest first.

1. Drop the photo in `public/photos/`, for example `06-new-chapter.jpg`.
2. Add a chapter to `story` in `src/content.js` with its `title`, `caption`, and `src`.

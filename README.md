# Samantha Turns 30

A temporary birthday invitation site for Samantha Elaine Goodwin.

Born October 14. Celebrating October 18. Inspired by Psalm 30.

## Local

```bash
npm install
npm run dev
```

## Host on Netlify

1. Push this folder to GitHub.
2. In Netlify, add a new site from that GitHub repo.
3. Build command: `npm run build`
4. Publish directory: `dist`
5. After the first deploy, Netlify Forms will collect RSVPs and guestbook notes.

RSVPs show up in Netlify → Forms.
